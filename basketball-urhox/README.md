# 篮途 · 从街球场到世界之巅

原创篮球生涯模拟游戏，基于 **UrhoX（TapTap Code）** 引擎，Lua 5.4。
竖屏手游形态，热血漫画分镜风格美术。

---

## 核心玩法

本作不止是文字推进——提供 **两种比赛模式** + **5 个可操作玩法**，全部由属性驱动手感。

### 比赛模式（主页可切换）

| 模式 | 玩法 |
|------|------|
| **操作比赛**（🎮） | 回合制操作。每场 16 个回合，玩家亲自打：突破（读防守重心变向）→ 投篮（时机条出手）；防守回合读对手动向预判。比分实时累积 |
| **文字直播**（📺） | 四节制比分推演 + 逐条解说流 + 关键回合决策卡。节奏更快，适合快速推进赛季 |

### 训练馆玩法

| 玩法 | 操作 | 属性影响 |
|------|------|---------|
| **投篮时机条** | 力度游标来回摆动，在绿色区域点击出手 | 【得分】决定绿区宽度，体能低于 40 明显缩窄 |
| **一对一突破** | 观察防守者重心倾斜方向，选择左/右变向 | 【组织】+【体能】决定成功率；AI 会记忆你的习惯，连续同侧会被识破 |
| **防守读心** | 阅读对手动向提示，预判突破/投篮/传球 | 【防守】越高提示越准，低属性会收到误导性假提示 |
| **斗牛赛** | 1v1 单挑，先到 11 分获胜，串联突破→投篮→防守 | 三种玩法的综合考验 |
| **战术板** | 布置进攻战术与防守策略 | 直接乘算进比赛比分推演 |

## 广告系统（激励视频）

共 **13 个广告位**，全部由玩家主动选择，按钮上直接写明行为与收益。
配额采用**懒重置**（读取时对比游戏内日期/赛季自动清零），无定时器。

### 日配额
| 广告位 | 奖励 |
|--------|------|
| 立即痊愈 | 清除全部伤停天数（每日 1 次） |

### 赛季配额
| 广告位 | 奖励 | 次数/季 |
|--------|------|--------|
| 属性点 +5 | 经验池 +500 | 20 |
| 技能点 +3 | 技能点入账 | 5 |
| 潜力突破 +5 | 单项能力上限 +5（可突破 99） | 3 |
| 领取代言邀约 | 获得一份商业代言合约 | 3 |
| 领取头奖 | 奖金直接入账 | 3 |
| 训练经验 ×1.5 | 本季训练收益 +50% | 无限制 |
| 刷新转会报价 | 重新生成报价 | 2 |
| 天赋升级 | 指定天赋档位 +1 | 1 |
| 指定下家 | 任选球队加盟 | 1 |
| 青训加速 | 提前看到成材结果 | 3 |

### 接入纪律（与 SDK 契约一致）
- 只有 `result.success == true` 才发奖，提前关闭/失败/超时一律不发
- **配额只在成功回调里扣**，失败不扣，玩家可重试
- 单飞锁 + 90 秒看门狗 + 一次性完成状态：防重复发奖、防卡死 UI
- 看门狗超时只结束为失败，绝不推断成功

## 生涯系统

- **5 项核心能力**：得分 / 组织 / 防守 / 体能 / 意识（0-99，可突破至 119）
- **5 个生涯阶段**：街头球场 → 高中联赛 → 大学联赛 → 职业联赛 → 传奇殿堂
- **5 个场上位置**：控卫 / 分卫 / 小前 / 大前 / 中锋
- **周循环**：每周选择训练行动，累积经验池
- **伤病系统**：比赛后按体能/年龄/风险掷骰，伤停期间无法出战、训练效果减半
- **成长系统**：经验池兑换属性点、潜力上限约束、技能点、天赋
- **商业系统**：代言合约（每赛季收入，年数到期自动移除）
- **赛季结算**：场均得分、全明星、常规赛 MVP、总冠军、年薪续约
- **年龄曲线**：18 岁前 ×1.6 成长，31 岁后衰退

## 剧情事件

40+ 张原创事件卡，分赛前 / 赛后 / 日常 / 里程碑 / 赛季末五类：
- 每个选项带真实数值效果（属性、士气、体能、人气、金钱）
- 同类事件有冷却，`once` 事件整生涯只触发一次
- 文案为热血动漫风原创

---

## 美术与音频

全部 AI 生成，无第三方素材：
- **美术**：23 张动漫手绘风资源（赛璐璐平涂 + 粗黑描边）
  - 7 张场景背景、9 张事件插图、5 张属性图标 + Logo + 头像
- **音频**：2 首 BGM（日常励志 / 比赛燃向）+ 12 个音效

## UI 风格

**热血漫画分镜风**——刻意区别于常见暗色圆角卡片：
- 米黄纸底 + 墨黑粗描边（3px）+ 直角分镜格
- 高饱和橙红主色 + 高光黄广告按钮
- 返回键统一固定在左上角（`Common.TopBar`）

## 技术要点

- 引擎：UrhoX（基于 Urho3D 1.8，API 95% 兼容），Lua 5.4
- UI：`urhox-libs/UI`（Yoga Flexbox + NanoVG），竖屏，`UI.Scale.DEFAULT`
- 存档：`File` API + `cjson`，单文件 JSON
- 广告：`sdk:ShowRewardVideoAd(callback)`，无硬编码广告位 ID
- 无 raw NanoVG 调用，纯 UI 组件构建
