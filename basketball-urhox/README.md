# 篮途 · 从街球场到世界之巅

原创篮球生涯模拟游戏，基于 **UrhoX（TapTap Code）** 引擎，Lua 5.4。
竖屏手游形态，热血漫画分镜风格美术。

---

## 核心玩法

本作不止是文字推进——比赛之外提供 **5 个可操作的核心玩法**，全部由属性驱动手感：

| 玩法 | 操作 | 属性影响 |
|------|------|---------|
| **投篮时机条** | 力度游标来回摆动，在绿色区域点击出手 | 【得分】决定绿区宽度，体能低于 40 明显缩窄 |
| **一对一突破** | 观察防守者重心倾斜方向，选择左/右变向 | 【组织】+【体能】决定成功率；AI 会记忆你的习惯，连续同侧会被识破 |
| **防守读心** | 阅读对手动向提示，预判突破/投篮/传球 | 【防守】越高提示越准，低属性会收到误导性假提示 |
| **斗牛赛** | 1v1 单挑，先到 11 分获胜，串联突破→投篮→防守 | 三种玩法的综合考验 |
| **战术板** | 布置进攻战术与防守策略 | 直接乘算进比赛比分推演 |

### 玩法与生涯的闭环

```
训练馆练手感 → 属性成长 → 操作容错更高 → 比赛表现更好 → 生涯推进
     ↑                                                        ↓
     └──────────────── 比赛结果与事件奖励 ────────────────────┘
```

战术板的选择会**真实影响比赛模拟**：`跑轰`（进攻 ×1.25 / 防守 ×0.85）与 `铁血防守`（进攻 ×0.85 / 防守 ×1.28）带来不同的胜负走向。

## 生涯系统

- **5 项核心能力**：得分 / 组织 / 防守 / 体能 / 意识（0-99）
- **5 个生涯阶段**：街头球场 → 高中联赛 → 大学联赛 → 职业联赛 → 传奇殿堂
- **5 个场上位置**：控卫 / 分卫 / 小前 / 大前 / 中锋，各有属性倾向
- **周循环**：每周选择训练行动（加练投篮、录像分析、商业活动、休息恢复…）
- **赛季结算**：场均得分、全明星、常规赛 MVP、总冠军、年薪续约
- **年龄成长曲线**：18 岁前 ×1.6 成长，31 岁后开始衰退

## 剧情事件

40+ 张原创事件卡，分赛前 / 赛后 / 日常 / 里程碑 / 赛季末五类：

- 每个选项带真实数值效果（属性、士气、体能、人气、金钱）
- 同类事件有冷却，`once` 事件整生涯只触发一次
- 文案为热血动漫风原创，无外部素材

## 美术与音频

全部 AI 生成，无第三方素材：

- **美术**：23 张动漫手绘风资源（赛璐璐平涂 + 粗黑描边）
  - 7 张场景背景（街头球场 / 高中馆 / 大学馆 / 职业万人馆 / 更衣室 / 训练馆 / 主菜单）
  - 9 张事件插图（跳投 / 暴扣 / 盖帽 / 抢断 / 发布会 / 受伤 / 夺冠 / 训练 / 球迷）
  - 5 张属性图标 + Logo + 头像
- **音频**：2 首 BGM（日常励志 / 比赛燃向）+ 12 个音效（空心入网 / 打铁 / 暴扣 / 盖帽 / 裁判哨 / 观众欢呼 / 运球 / 球鞋摩擦…）

## UI 风格

**热血漫画分镜风**——刻意区别于常见暗色圆角卡片：

- 米黄纸底 + 墨黑粗描边（3px）+ 直角分镜格
- 高饱和橙红主色 + 高光黄强调色
- 分镜格标题条、粗描边标题字、贴纸式标签

```

│   ├── EventSystem.lua      # 事件卡筛选、触发与效果结算
│   └── Audio.lua            # 音效与 BGM 管理
├── Data/
│   ├── Events.lua           # 40+ 张原创事件卡文案
│   └── Teams.lua            # 球队与出身地数据

    ├── ScreenMenu.lua       # 主菜单

    ├── ScreenHub.lua        # 生涯主页
    ├── ScreenMatch.lua      # 比赛文字直播
    ├── ScreenEvent.lua      # 剧情事件卡
    ├── ScreenTraining.lua   # 训练馆 / 战术板 / 结算
    └── ScreenMini.lua       # 投篮 / 突破 / 防守玩法界面
assets/
├── bg/       # 场景背景
├── ev/       # 事件插图
├── icon/     # 图标与 Logo
```

## 技术要点

- 引擎：UrhoX（基于 Urho3D 1.8，API 95% 兼容），Lua 5.4
- UI：`urhox-libs/UI`（Yoga Flexbox 布局 + NanoVG 渲染）
- 分辨率：`UI.Scale.DEFAULT`（DPR 自适应），竖屏
- 存档：`File` API + `cjson`，单文件 JSON
- 无 raw NanoVG 调用，纯 UI 组件构建
